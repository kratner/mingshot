# M2: the editor (in progress)

PLAN.md §6, tracked in kratner/planning#32. Three steps: editor basics, the rest of the tools, copy with metadata.

## Step 1: editor basics (2026-11-26)

- **Opening it:** After capture → **Edit** opens each capture in an editor window; the status line's **Edit** opens
  the last capture; **Open…** in the capture window reopens a saved capture (its `.png` or `.mingshot`) with its
  annotations editable.
- **Tools:** Select (V), Arrow (A), Box (R), Text (T; Enter finishes, Shift+Enter a new line, Esc cancels,
  double-click to edit). Six colours (Four Ounces red first) and S / M / L widths in points (2 / 4 / 8), scaled by
  the capture's pixels per point so they look the same on 1× and 2× captures. Select and drag to move; Delete
  removes; picking a colour recolours the selected shape. Undo ⌘Z, redo ⇧⌘Z. Copy ⌘C, Save ⌘S.
- **Exact pixels:** the capture is shown as a plain image under a transparent Konva stage that holds only the
  annotations. Copy and Save render that layer at the capture's full pixel size and send it to Rust, which
  composites it over the untouched original in the original's colour space (`editor.rs`; the layer is tagged sRGB,
  as the canvas draws). `cargo run --example composite_probe`: with no annotations, every pixel of every display's
  capture comes out identical.
- **The document:** annotations are plain data in image pixels (`src/scene.ts`), so the same model can be driven from
  a CLI or MCP server later (PLAN.md §7.10). Saving writes the annotated PNG and, beside it, the `.mingshot` with the
  annotations and (once there are any) the clean original as base64, so the PNG shows the markup anywhere while
  MingShot reopens the capture clean underneath.
- **Tests:** `npm run test:ui` (scene model: add / move / remove, undo / redo, ids, normalising, clicks aren't
  shapes); `cargo test` (sidecar round trip with annotations and original); `npm run test:editor` (headless
  Chromium on a mock backend: draws arrow, box and text, undo/redo, click isn't a shape, select + delete, Copy sends
  an 800×500 layer with the shapes where drawn and nothing else).
